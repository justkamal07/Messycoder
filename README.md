# Messycoder
Just Learn coding to execute your design, King! 

--- 


## What is this?

A collection of small HTML, CSS and JavaScript practice pages, written while learning to turn designs into working code.

## Inside

Examples include CSS animations, a calculator, an expense tracker, a flexbox layout, a form and registration page, an image gallery and a guess-the-number game. Each page is a standalone `.html` file. Open it in a browser to run it.
